⌨️ Radial Keyboard Controls
Input--	Action
D-Pad--	Select radial direction
A/B/X/Y--	Type selected character
LB/RB--	Switch character mode
Hold L3+R3+LB+RB (1.2s)--	Show/Hide on-screen keyboard
L3 double-tap--	Toggle overlay drag mode
Right stick--	Move overlay while in drag mode

----Radial Mouse Control----
Start radial_mouse.pyw
R3(stick click) quad-click    Toggle mouse mode

🧠 Character Modes LB+RB (while in OSK)

Lowercase

CAPS

Symbols

Numbers

Shortcut combos (Ctrl+C, etc.)

🖥️ System Behavior

Runs minimized to system tray

Invisible at startup

Safe manual exit via tray icon

How to install
Install Python 24.2
Install all the required sources (copy and pate each command into command prompt running as admin(search command prompt right click run as administrator(after installing python)))

pip install keyboard

pip install pyautogui

pip install tkinter

pip install time

pip install ctypes

pip install pystray

pip install threading
